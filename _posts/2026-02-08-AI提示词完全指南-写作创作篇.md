## 通用文章写作

### 万能文章写作模板

**适用场景：** 需要撰写各种类型文章的场合，可以根据不同的风格、受众和目标来定制文章内容

**提示词：**
{% raw %}
```
Write an article about {{Topic}}. Use the style of {{Style}} such as {{Style_Examples}}. The intended audience is {{Audience}}. Mention {{Mentions}}. Outline the {{Arguments}}. Use only reliable sources such as {{Source_Examples}}. Write {{Wordcount}} words.
```
{% endraw %}

**使用说明：**
> 这是一个通用的文章写作模板，通过替换变量可以适应不同的写作需求。

**示例：**
> Write an article about the concept of Artificial General Intelligence (AGI). Use the style of newspapers such as The New York Times, The Economist, and The Guardian. The intended audience is the general public. Mention the historical roots of the term AGI. Address the current predictions of AI researchers about the possibility of AGI and the potential timelines. Outline the arguments of both the sceptics and those who believe we should take the possibility of AGI seriously instead of dismissing it as mere science fiction. Use only reliable sources. Write at least 500 words.

## 活人感写作

### 1. 口语化改写

**适用场景：** 让文章更具人情味，避免AI腔调

**提示词：**
```
请用真人的语气改写以下内容，要求：
1. 使用口语化表达，避免书面语和官话
2. 加入个人观点和情感
3. 使用具体的例子而不是抽象概念
4. 适当使用"我觉得"、"其实"、"说实话"等口语词汇
5. 保持逻辑清晰但表达自然

[待改写内容]
```

---

### 2. 故事化叙述

**适用场景：** 让干货内容更有吸引力

**提示词：**
```
请将以下知识点改写成故事形式，要求：
1. 用一个具体的场景或人物开头
2. 通过情节推进自然引出知识点
3. 加入细节描写增强真实感
4. 在故事中穿插个人思考
5. 用故事结局点题

[待改写内容]
```

---

### 3. 对话式写作

**适用场景：** 增强读者参与感

**提示词：**
```
请用对话的方式重写以下内容，要求：
1. 像跟朋友聊天一样，提出问题并回答
2. 预判读者可能的疑问并解答
3. 使用"你可能会想"、"有人问我"等短语
4. 适当使用反问句引发思考
5. 保持专业但亲切的语气

[待改写内容]
```

## 爆款文案

### 1. 小红书风格文案

**适用场景：** 社交媒体种草、产品推荐

**提示词：**
{% raw %}
```
请为{{产品/主题}}创作小红书风格的文案，要求：

1. **标题**（3个备选）
   - 使用emoji吸引眼球
   - 包含痛点或好处
   - 制造紧迫感或稀缺性

2. **正文结构**
   - 开头：直击痛点/展示结果
   - 中间：分点列出亮点（用emoji）
   - 结尾：行动号召

3. **文案风格**
   - 口语化、真实感
   - 多用感叹号和emoji
   - 分段明确，易读性强

4. **关键词**
   - 至少包含5个相关话题标签
```
{% endraw %}

**示例模板：**
```
🔥真的绝了！这个[产品]让我[解决了什么问题]！

姐妹们，作为[身份]，我真的太懂[痛点]了😭
直到我遇到了这个[产品]，人生都不一样了！✨

💡亮点分享：
✅ [亮点1] - [具体效果]
✅ [亮点2] - [具体效果]  
✅ [亮点3] - [具体效果]

👉使用感受：
[第一段]
[第二段]
[第三段]

💰价格只要[价格]，真的超值！
[行动号召]

#话题1 #话题2 #话题3 #话题4 #话题5
```

### 2. 朋友圈广告文案

**适用场景：** 微信朋友圈营销、个人IP打造

**提示词：**
{% raw %}
```
为{{产品/服务}}创作朋友圈文案，要求：

1. **开头**（选其一）
   - 个人故事/经历
   - 提出问题/痛点
   - 展示成果/对比

2. **中间**
   - 不超过9张图的图文配置建议
   - 突出3个核心卖点
   - 加入真实使用场景

3. **结尾**
   - 软性转化，不硬广
   - 制造互动（评论/私信）
   - 限时优惠（可选）
```
{% endraw %}

### 3. 视频号/抖音脚本

**适用场景：** 短视频内容创作

**提示词：**
{% raw %}
```
为{{主题}}创作短视频脚本（30-60秒），要求：

1. **前3秒钩子**
   - 抛出悬念/惊人数据
   - 或展示结果/冲突

2. **主体内容**（15-40秒）
   - 分3个要点
   - 每个要点一句话+场景
   - 节奏紧凑，信息密集

3. **结尾**（5-10秒）
   - 金句总结
   - 引导互动（点赞/关注/评论）

4. **画面建议**
   - 每个镜头的画面描述
   - 字幕关键词
   - BGM建议
```
{% endraw %}

### 4. 标题党优化器

**适用场景：** 提升文章点击率

**提示词：**
```
请为以下文章创作10个吸引眼球的标题，要求：

原文主题：[主题]
目标受众：[受众]

标题类型（每种2个）：
1. **数字型**：使用具体数字（如"7个方法"、"30天"）
2. **悬念型**：制造好奇（如"你绝对想不到..."）
3. **痛点型**：直击痛点（如"为什么你总是..."）
4. **利益型**：强调好处（如"让你轻松..."）
5. **对比型**：前后对比（如"从...到..."）

每个标题要求：
- 不超过25个字
- 包含关键词
- 符合平台风格
- 避免夸大和标题党陷阱
```

### 5. 产品描述文案

**适用场景：** 电商产品详情页

**提示词：**
{% raw %}
```
为{{产品}}创作电商详情页文案，包括：

1. **一句话卖点**
   - 15字内说清核心价值

2. **5个购买理由**
   - 每个理由：问题+解决方案+效果

3. **使用场景**（3个）
   - 描绘用户使用画面
   - 突出便利性/效果

4. **规格参数**
   - 用通俗语言解释专业参数
   - 对比竞品优势

5. **常见疑问解答**
   - 预判5个常见问题
   - 简洁有力的回答

6. **购买促销**
   - 限时优惠话术
   - 赠品/保障说明
```

## 写作技巧

### 通用优化原则

1. **明确受众**：了解读者是谁，他们的需求是什么
2. **突出价值**：清楚传达读者能获得什么
3. **真实可信**：使用具体案例和数据
4. **结构清晰**：善用分段、小标题、列表
5. **行动导向**：明确的CTA（Call to Action）

### 避坑指南

❌ **避免**：
- AI痕迹过重（官话、套话）
- 堆砌关键词
- 夸大其词、虚假承诺
- 长篇累牍、重点不明
- 纯硬广、无价值内容

✅ **建议**：
- 真实经历、具体案例
- 自然融入关键词
- 实事求是、有理有据
- 段落精简、重点突出
- 内容为王、软性转化
