## UX研究与设计

### 1. 用户研究数据分析

**适用场景：** 整理和分析用户研究数据，提取关键发现

**提示词：**
{% raw %}
```
Act as an experienced UX researcher. I'll provide you with responses from {{Number}} participants in {{Experiment}} in which my goal is {{Goal}}. You need to summarize the key findings according to their responses.
```
{% endraw %}

**使用说明：**
> 适用于整理用户研究数据，提取关键发现的场景

---

### 2. UX设计优化

**适用场景：** 优化网站或产品用户体验

**提示词：**
```
I want you to act as a Sr. UX Designer with more than 10 years of experience in the field. Your primary goal is to ensure that the user experience of a product or service is as seamless, intuitive, and engaging as possible. You will create engaging useful, usable, and enjoyable experiences for users of #your product name. Your task is to improve the user experience of a #your product like app, website, web application and more in a creative way.
```

**使用说明：**
> 适用于需要优化产品用户体验的场景，特别是网站、应用等数字产品

### 3. 用户画像创建

**适用场景：** 构建详细的用户画像

**提示词：**
```
帮我创建【产品/服务】的用户画像（User Persona）：

基础信息：
- 产品类型：[类型]
- 目标市场：[市场]
- 已知用户特征：[特征]

请创建3-5个用户画像，每个包含：

1. **基本信息**
   - 姓名、年龄、职业
   - 收入水平、教育背景
   - 生活地区、家庭状况

2. **行为特征**
   - 日常习惯
   - 使用场景
   - 技术熟练度

3. **痛点与需求**
   - 主要痛点（3-5个）
   - 核心需求
   - 期望解决方案

4. **目标与动机**
   - 短期目标
   - 长期目标
   - 使用产品的动机

5. **渠道偏好**
   - 信息获取渠道
   - 购买决策因素
   - 沟通偏好
```

###5. 可用性测试计划

**适用场景：** 设计可用性测试方案

**提示词：**
```
为【产品功能】设计可用性测试方案：

测试目标：[目标]
测试对象：[用户群体]

请提供完整的测试计划：

1. **测试目标**
   - 主要研究问题（3-5个）
   - 成功指标

2. **参与者招募**
   - 目标人数
   - 筛选标准
   - 招募渠道

3. **测试任务**（5-8个）
   - 任务描述
   - 任务目的
   - 成功标准
   - 预期用时

4. **测试流程**
   - 前期准备
   - 欢迎与介绍
   - 任务执行
   - 后续访谈
   - 总结感谢

5. **数据收集**
   - 定量数据（完成率、用时、错误率等）
   - 定性数据（用户反馈、观察记录）
   - 工具和方法

6. **问题清单**
   - 背景问题（3个）
   - 任务后问题（每个任务2-3个）
   - 总结问题（3-5个）
```

## 产品需求文档

### 1. PRD完整模板

**适用场景：** 撰写产品需求文档

**提示词：**
```
帮我撰写【产品功能】的PRD（产品需求文档）：

背景信息：
- 产品名称：[名称]
- 功能名称：[功能]
- 目标用户：[用户]
- 业务目标：[目标]

请按以下结构撰写PRD：

## 1. 产品概述
- 背景与机会
- 产品定位
- 核心价值

##2. 目标用户
- 用户画像
- 使用场景
- 用户痛点

## 3. 功能需求

### 3.1 功能清单
| 功能模块 | 优先级 | 描述 |
|---------|--------|------|
| [模块1] | P0     | [描述] |
| [模块2] | P1     | [描述] |

### 3.2 详细需求（针对每个P0功能）

**功能名称：** [名称]

**用户故事：** 作为[角色]，我想要[功能]，以便[价值]

**功能描述：**
- 功能入口：
- 操作流程：
  1. 步骤1
  2. 步骤2
  3. ...
- 页面元素：
- 交互说明：
- 异常处理：

**原型/线框图需求：**
[描述需要的原型图]

## 4. 非功能需求
- 性能要求：
- 安全要求：
- 兼容性要求：
- 可用性要求：

## 5. 数据需求
- 需要采集的数据
- 数据流转
- 数据埋点

## 6. 技术方案（概述）
- 前端技术栈
- 后端架构
- 第三方服务

## 7. 上线计划
- 开发排期
- 测试计划
- 灰度发布策略
- 全量上线时间

## 8. 风险与依赖
- 技术风险
- 业务风险
- 外部依赖

## 9. 成功指标
- 核心指标
- 目标值
- 监控方式
```

### 2. 用户故事撰写

**适用场景：** 将需求转化为用户故事

**提示词：**
```
将以下需求转化为用户故事（User Story）：

需求描述：[需求]

请提供：
1. **用户故事**
   - 格式：作为[用户角色]，我想要[功能]，以便[达成目标/获得价值]
   
2. **验收标准**（AC: Acceptance Criteria）
   - Given [前置条件]
   - When [用户操作]
   - Then [预期结果]
   （至少3-5条）

3. **故事点估算**
   - 复杂度评估（1/2/3/5/8/13斐波那契数列）
   - 理由说明

4. **依赖与风险**
   - 技术依赖
   - 业务依赖
   - 潜在风险
```

```
请按以下维度分析：

## 1. 基本信息
| 维度 | 我的产品 | 竞品1 | 竞品2 | 竞品3 |
|-----|---------|------|------|------|
| 产品定位 | | | | |
| 目标用户 | | | | |
| 核心功能 | | | | |
| 商业模式 | | | | |
| 市场份额 | | | | |

## 2. 功能对比
- 核心功能对比表
- 独特功能列举
- 功能完整度评分

## 3. 用户体验
- UI/UX设计风格
- 交互流程
- 易用性评分

## 4. 运营策略
- 获客渠道

```

```
- 目标用户：[用户]

请提供完整的设计系统规划：

## 1. 设计原则
- 原则1：[名称] - [描述]
- 原则2：[名称] - [描述]
- 原则3：[名称] - [描述]

## 2. 基础样式（Foundation）

- Primary Color: [色值] - [使用场景]
- Secondary Color: [色值] - [使用场景]

**中性色**
- Gray Scale: [列出所有灰度值]

**功能色**
- Success: [色值]
- Warning: [色值]
- Error: [色值]
- Info: [色值]
```
