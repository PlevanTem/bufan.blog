## 文献综述

### 1. Related Work 撰写

**适用场景：** 撰写学术论文的Related Work或文献综述部分

**提示词：**
```
You're a top university professor and a reviewer from 【期刊名称】 journals. My goal is to provide a background of related work on 【研究主题】. My outline is 【大纲】. 

You can refer to paper in the list and more if you want: 
1. XXX
2. XXX

You need to do the tasks below: 
1. Write a 【页数】 pages related work according to the writing and wording styles of above journals. 
2. Reference to academic paper
3. Provide a name list of all references
```

**使用说明：**
> 适合场景：文献综述、literature review、related work

---

### 2. 个人陈述/动机信

**适用场景：** 留学申请文书、个人陈述

**提示词：**
```
Role: You're a professional writer and college applicant examiner who knows well about university and colleges admissions service. You're good at storytelling and writing for Personal Statement (PS)/Letter of Motivation.

I'll provide information about myself and the university program that I intend to apply. You need to:
#1. Dive into my experience and enrich my stories based on my info, discover shine points and advantages 
#2. Identify the requirements and specialities of the uni program, summarize the applicant persona they're looking for
#3. Create an outline of my PS that matches the uni program, considering findings of #1 and #2
#4. Based on the outline of #3, write a good PS for my application at your best ability.
```

**注意事项：**
- ❌ 避免拼写和语法错误
- ❌ 避免过度使用华丽的语言和无意义的陈词滥调
- ❌ 不要无休止地列出课外活动
- ❌ 不要过度使用引用或断章取义
- ❌ 不要告诉读者他们已经知道的事情
- ✅ 注意字数/字符限制

### 3. 课程描述撰写

**适用场景：** 留学申请的课程描述

**提示词：**
{% raw %}
```
Role: You're an admissions officer in a top university and a native English speaker. 
Task: I intend to apply {{major}}. Help me write course descriptions of my provided courses so to fit the requirement of applying major. 

A course description:
- should be no longer than 125 words
- should begin most sentences with a verb
- should be student-centered and explain how the reader would benefit from the course
- should be written in the present tense and active voice
- should not begin with "This course…"
- should not contain deliverables like "student will learn…" but instead use "students will have an opportunity to learn…"
- should not include the names of software, technology, or texts that change term to term
- course descriptions should be able to carry over for multiple terms and not need frequent updating
- should not incorporate prerequisites/prerequisites, intended delivery mode, equivalencies, fees, etc., but may contain if it is repeatable and how many times
- should not include general education attributes as those will be entered elsewhere, as additional course details.
```
{% endraw %}

**使用说明：**
> 确保描述符合目标院校的要求和格式

## 论文写作

### 1. 论文润色与优化

**适用场景：** 按照目标期刊的写作风格对论文进行润色和优化

**提示词：**
{% raw %}
```
You're a top university professor mentor and a reviewer from {{期刊名称}} Journal. My goal is {{目标}}. I will provide you with my written text. You need to do the tasks below: 

1. List proofread feedback for improvement according to the writing and wording styles of above journals. 
2. Summarize reflections upon the reasoning and logic process that I did to come up the written text.
3. Based on the writing logic, you can ask me a series of questions to better achieve my goal. 

Do you understand?
```
{% endraw %}

**使用说明：**
> 可直接按目标期刊的写作风格进行润色，一般情况下用Purdue Writing Lab的风格润色即可

**优点：**
1. 根据期刊风格和domain用词习惯提供润色建议
2. 测试GPT对提供的内容是否理解来判断润色可靠性
3. 通过GPT强大的模型能力进行反问以反思/启发写作

### 2. 审稿意见整理

**适用场景：** 论文投稿后整理审稿意见，制定修改计划

**提示词：**
```
I'll provide reviews of my paper 【论文标题】. You need to organize reviews in a table. The first column you need to categorize the topics of the reviews. The second column cite AC's reviews for each theme. Third column write a revision plan for each theme. Do you understand?
```

**使用说明：**
> 适合场景：论文投稿后快速整理reviewers的feedback，提交你的revision plan

### 3. 研究问题提炼

**适用场景：** 明确研究方向，提炼研究问题

**提示词：**
```
作为学术研究顾问，帮我提炼研究问题：

研究领域：[领域]
初步想法：[描述]

请帮我：
1. 评估这个研究方向的新颖性和可行性
2. 提出3-5个具体的研究问题（Research Questions）
3. 为每个研究问题建议可能的研究方法
4. 指出潜在的研究难点和创新点
5. 推荐5-10篇必读文献
```

---

### 4. 论文结构规划

**适用场景：** 规划论文整体结构

**提示词：**
```
帮我规划一篇【研究类型】论文的结构：

研究主题：[主题]
研究问题：[问题]
主要发现：[发现]

请提供：
1. **Abstract**（150-250字）
   - 研究背景
   - 研究问题
   - 方法
   - 主要发现
   - 意义

2. **Introduction**
   - 研究背景（2-3段）
   - 研究问题和假设
   - 研究意义
   - 论文结构

3. **Literature Review**
   - 主要研究主题（3-5个）
   - 每个主题的核心文献
   - 研究缺口

4. **Methodology**
   - 研究设计
   - 数据收集方法
   - 数据分析方法
   - 研究局限

5. **Results**
   - 主要发现（3-5个）
   - 图表建议

6. **Discussion**
   - 结果解释
   - 与已有研究的对比
   - 研究意义
   - 局限性
   - 未来研究方向

7. **Conclusion**
   - 核心发现总结
   - 研究贡献
   - 实践启示
```

## 论文降重

### 1. 段落改写

**适用场景：** 降低查重率，保持原意

**提示词：**
```
请改写以下段落，要求：
1. 保持原文核心意思不变
2. 更换同义词和表达方式
3. 调整句式结构
4. 改变段落组织方式
5. 保持学术规范和专业性

原文：
[待改写段落]
```

---

### 2. 文献综述降重

**适用场景：** 文献综述部分查重率过高

**提示词：**
```
请重写以下文献综述段落，要求：
1. 用自己的话总结文献观点
2. 不直接引用原文表述
3. 加入批判性思考和对比分析
4. 突出不同研究之间的关系
5. 保持学术引用规范

原文文献综述：
[待改写内容]

参考文献：
1. [文献1]
2. [文献2]
```

---

### 3. 整篇降重优化

**适用场景：** 全文查重率过高，需要系统性降重

**提示词：**
```
这是我论文的【章节名称】部分，查重率为【%】，请帮我降重：

降重策略：
1. **同义替换**
   - 专业术语保持不变
   - 普通词汇替换同义词
   - 避免过度替换影响可读性

2. **句式转换**
   - 主动句↔被动句
   - 长句拆分为短句
   - 短句合并为长句
   - 调整定语从句位置

3. **段落重组**
   - 调整论述顺序
   - 重新组织论据
   - 改变论证逻辑

4. **内容优化**
   - 删除冗余表述
   - 补充原创观点
   - 加入批判性分析

原文：
[待降重内容]
```

---

### 4. 引用规范检查

**适用场景：** 确保引用格式正确

**提示词：**
```
请检查以下段落的引用规范，按【APA/MLA/Chicago/Harvard】格式：

检查要点：
1. 直接引用是否正确标注
2. 间接引用是否规范
3. 文内引用格式是否一致
4. 引用列表格式是否标准
5. 是否存在引用缺失

段落：
[待检查内容]

参考文献列表：
[文献列表]
```

## 学术写作技巧

### 高质量论文特征

✅ **必备要素：**
1. **明确的研究问题**：具体、可研究、有意义
2. **扎实的文献综述**：全面、批判性、有逻辑
3. **严谨的研究方法**：可复制、可靠、有效
4. **清晰的研究发现**：客观、准确、有意义
5. **深入的讨论分析**：解释充分、联系紧密
6. **专业的学术写作**：规范、清晰、准确

### 常见问题与解决

❌ **问题** → ✅ **解决方案**

1. **研究问题不明确**
   - → 使用"What/Why/How"框架明确问题
   - → 确保问题具有研究价值和可行性

2. **文献综述堆砌**
   - → 建立批判性分析框架
   - → 突出研究缺口和创新点

3. **方法描述不清**
   - → 详细说明每个步骤
   - → 提供足够细节使研究可复制

4. **结果呈现混乱**
   - → 按逻辑顺序组织发现
   - → 善用图表清晰展示

5. **讨论浮于表面**
   - → 深入解释结果成因
   - → 联系理论和实践意义

6. **查重率过高**
   - → 用自己的话总结观点
   - → 规范使用引用标注
