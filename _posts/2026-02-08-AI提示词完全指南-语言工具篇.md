## 翻译

### 1. 信雅达翻译

**适用场景：** 高质量文本翻译

**提示词：**
```
请按照"信、达、雅"的标准将以下内容从【源语言】翻译成【目标语言】：

原文：
[待翻译内容]

翻译要求：
1. **信（Faithfulness）**：忠实原文，准确传达原意
2. **达（Expressiveness）**：表达流畅，符合目标语言习惯
3. **雅（Elegance）**：文字优美，注重文采

请提供：
1. **直译版**：逐字逐句翻译
2. **意译版**：根据语境调整
3. **润色版**：在意译基础上优化表达

文本类型：[学术/商务/文学/技术/日常]
目标读者：[专业人士/普通大众/学生]

针对难点词汇或表达：
- [词汇1] - [翻译选择] - [理由]
- [词汇2] - [翻译选择] - [理由]
```

### 2. 专业领域翻译

**适用场景：** 特定领域的专业翻译

**提示词：**
```
作为【领域】专业译者，翻译以下内容：

领域：[医学/法律/金融/技术/科学]
文档类型：[论文/合同/报告/说明书]
专业级别：[入门/中级/高级]

原文：
[内容]

要求：
1. 使用该领域的专业术语
2. 遵循该领域的表达习惯
3. 保持专业术语的一致性
4. 附上术语表（中英对照）

请提供：
- 翻译正文
- 术语表
- 不确定项说明
- 参考资料建议
```

### 3. 本地化翻译

**适用场景：** 软件、网站等的本地化

**提示词：**
```
为【产品】进行本地化翻译：

源语言：[语言]
目标市场：[地区]
产品类型：[App/网站/游戏/软件]

内容：
[待翻译字符串]

本地化要求：
1. **文化适配**
   - 避免文化敏感内容
   - 使用本地习惯表达
   - 适配节日/习俗

2. **用户体验**
   - 文字长度控制（避免UI问题）
   - 保持一致的语气和风格
   - 易于理解

3. **技术规范**
   - 占位符保持不变（如%s, {0}）
   - HTML标签保留
   - 特殊字符处理

请提供：
- 翻译文本
- 长度对比（字符数）
- 潜在UI问题提示
- 测试建议
```

## OCR识别

### 1. OCR结果优化

**适用场景：** 优化OCR识别后的文字

**提示词：**
```
以下是OCR识别的文字，包含一些识别错误，请帮我修正：

OCR原文：
[粘贴OCR识别的内容]

请：
1. **纠正错字**
   - 识别并修正明显的OCR错误
   - 列出所有修改项

2. **格式整理**
   - 恢复正确的段落分隔
   - 修复标点符号
   - 调整排版

3. **逻辑检查**
   - 检查语句是否通顺
   - 补充可能缺失的标点
   - 标注不确定的部分

输出格式：
- 修正后的完整文本
- 修改列表（原文→修正）
- 不确定项（需人工确认）
```

### 2. 手写文字识别优化

**适用场景：** 手写OCR结果处理

**提示词：**
```
这是一份手写笔记的OCR识别结果，可能存在较多错误：

识别结果：
[内容]

笔记类型：[课堂笔记/日记/会议记录]
背景信息：[主题/领域]

请：
1. 根据上下文推断正确文字
2. 保持笔记的原有结构（标题/要点/注释）
3. 补充可能的遗漏内容
4. 标注高度不确定的地方

输出：
- 整理后的笔记
- 推断理由说明
- 需要确认的部分
```

## 口语训练

### 1. 英语口语纠错

**适用场景：** 提升英语口语表达

**提示词：**
```
我想表达：[中文意思]

我的英文表达：[你的英文]

请：
1. **纠正语法错误**
   - 时态
   - 主谓一致
   - 冠词使用

2. **优化表达**
   - 更地道的说法
   - 更简洁的表达
   - 更正式/非正式的版本（如适用）

3. **提供替代表达**（3个）
   - 同义表达
   - 不同语气
   - 不同场景的说法

4. **发音提示**
   - 重读音节
   - 连读现象
   - 易错发音

5. **例句**
   - 相似场景的使用例句（3个）
```

### 2. 情景对话练习

**适用场景：** 特定场景的对话训练

**提示词：**
```
帮我进行【场景】的英语对话练习：

场景：[机场/餐厅/面试/商务会议/问路]
难度：[初级/中级/高级]

请：
1. **设计情景对话**
   - A: [对方]
   - B: [我]
   （10-15轮对话）

2. **关键表达**
   - 必备句型（5个）
   - 常用词汇（10个）
   - 礼貌用语

3. **角色扮演**
   - 扮演对方，与我练习
   - 根据我的回答给出反馈
   - 提供更好的表达建议

4. **常见错误**
   - 中国学习者常犯错误
   - 如何避免

开始对话吧！（我先说/你先说）
```

### 3. 发音训练

**适用场景：** 改善发音

**提示词：**
```
帮我训练【音标/单词】的发音：

目标：[specific sounds/words]
母语：[中文]

请提供：
1. **发音要点**
   - 舌位
   - 口型
   - 气流
   - 声带震动

2. **对比辨析**
   - 与相似音的区别
   - 常见混淆音对比

3. **练习词汇**
   - 简单词（10个）
   - 常用词（10个）
   - 句子（5个）

4. **记忆技巧**
   - 口诀
   - 联想方法
   - 对比参照

5. **自查方法**
   - 如何判断发音正确
   - 常见错误表现
```

## 学习建议

### 翻译技能提升
1. 对比阅读（原文+译文）
2. 尝试回译
3. 积累专业术语
4. 了解文化背景
5. 持续练习

### 口语提升路径
1. 模仿native speaker
2. 录音自我纠正
3. 影子跟读(Shadowing)
4. 实际对话practice
5. 系统学习音标
