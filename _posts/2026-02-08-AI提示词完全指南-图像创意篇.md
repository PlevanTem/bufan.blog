## AI图像生成

### 1. Midjourney提示词框架

**适用场景：** Midjourney/DALL-E/Stable Diffusion等AI绘画工具

**提示词模板：**
```
[主体] + [风格] + [环境] + [构图] + [光线] + [色彩] + [参数]

示例：
A majestic dragon [主体], 
in cyberpunk style [风格], 
flying over a neon-lit cityscape [环境], 
cinematic wide shot [构图], 
dramatic lighting with blue and purple tones [光线+色彩], 
--ar 16:9 --v 5 --q 2 [参数]
```

**详细说明：**
- **主体**：具体描述（人物/物品/场景）
- **风格**：艺术风格（写实/卡通/油画/赛博朋克/极简等）
- **环境**：背景设定（室内/室外/自然/城市）
- **构图**：视角和布局（特写/全景/俯视/仰视）
- **光线**：光照效果（自然光/戏剧性/柔和/强烈）
- **色彩**：色调方案（暖色/冷色/黑白/单色）
- **参数**：技术参数（分辨率/质量/版本等）

### 2. 常用风格关键词

**艺术流派：**
- `impressionism`（印象派）
- `surrealism`（超现实主义）
- `art nouveau`（新艺术运动）
- `bauhaus`（包豪斯）
- `ukiyo-e`（浮世绘）

**现代风格：**
- `minimalist`（极简）
- `isometric`（等轴测）
- `low poly`（低多边形）
- `vaporwave`（蒸汽波）
- `glitch art`（故障艺术）

**质量提升：**
- `highly detailed`
- `8k resolution`
- `professional photography`
- `award winning`
- `trending on artstation`

### 3. 图像提示词生成器

**适用场景：** 快速生成完整的AI绘画提示词

**提示词：**
```
我想生成以下图像，请帮我创建详细的AI绘画提示词：

图像描述：[简单描述你想要的图像]

请提供：
1. **英文提示词**（适用于Midjourney/DALL-E）
   - 详细版（100-150词）
   - 精简版（30-50词）

2. **中文提示词**（适用于文心一言/通义千问）

3. **风格建议**（3个不同风格方向）

4. **参数推荐**
   - 长宽比建议
   - 质量参数
   - 其他相关参数

5. **反向提示词**（需要避免的元素）

6. **优化建议**
   - 如何调整以获得更好效果
   - 常见问题及解决方案
```

## SVG设计

### 1. SVG图标生成

**适用场景：** 生成简洁的SVG图标代码

**提示词：**
```
请生成【图标主题】的SVG代码：

要求：
- 尺寸：24x24 或 48x48
- 风格：极简/线性/填充
- 颜色：单色/双色/彩色
- 用途：[UI图标/Logo/装饰]

请提供：
1. **SVG代码**
   - 完整的可用代码
   - 优化过的路径

2. **使用说明**
   - 如何调整颜色
   - 如何调整大小
   - 响应式适配

3. **变体**（3个）
   - 不同风格演绎
   - 不同复杂度版本

4. **导出建议**
   - 优化方法
   - 兼容性注意事项
```

### 2. SVG动画设计

**适用场景：** 创建SVG动画效果

**提示词：**
```
为【元素】创建SVG动画：

动画类型：[loading/hover/transition]
时长：[秒]
缓动函数：[ease/linear/cubic-bezier]

请提供：
1. **SVG+CSS代码**
2. **关键帧说明**
3. **性能优化建议**
4. **浏览器兼容性**
```

## 符号学

### 1. 符号学生图法

**适用场景：** 使用符号学原理设计图表

**提示词：**
```
使用符号学方法为【数据/概念】设计可视化图表：

数据/概念：[描述]

请按符号学三要素设计：

## 1. 形式（Form）
- 视觉表现形式选择
- 图形语言建议
- 布局方案

## 2. 意义（Meaning）
- 每个符号的含义
- 颜色的语义
- 空间关系的意义

## 3. 语境（Context）
- 目标受众理解程度
- 文化适配性
- 使用场景

## 4. 设计方案
- 完整设计描述
- 符号系统说明
- 视觉层级

## 5. 实现建议
- 工具推荐
- 实现步骤
```

## 创意娱乐

### 1. 抽象评论生成器

**适用场景：** 生成幽默的抽象评论

**提示词：**
```
为【作品/事件】生成抽象派艺术评论风格的文字：

对象：[描述]

请模仿抽象艺术评论家的语气，生成：
1. **开篇**：引用某位哲学家或艺术家的观点
2. **主体**：使用隐喻和象征手法进行解读
3. **结尾**：升华到人生/存在主义高度

要求：
- 措辞优雅晦涩
- 充满意象和比喻
- 若有若无的深意
- 略带幽默感

示例风格：
"这部作品是对后现代主义语境下个体存在性的深刻拷问，创作者通过解构传统叙事结构，在碎片化的视觉符号中编织了一张关于时间、记忆与遗忘的诗意之网..."
```

### 2. 魔法生物图鉴

**适用场景：** 创造趣味性内容

**提示词：**
```
创建一个全新的魔法生物：

请提供：

## 1. 基本信息
- **名称**（中英文）
- **分类**（如：飞行类/水生类/地栖类）
- **危险等级**（⭐-⭐⭐⭐⭐⭐）
- **稀有degree**（常见/罕见/传说）

## 2. 外观描述
- 整体形态
- 独特特征
- 体型大小
- 颜色纹理

## 3. 能力特性
- 魔法能力（3个）
- 物理特性（2个）
- 特殊技能

## 4. 生活习性
- 栖息地
- 饮食习惯
- 社会结构
- 繁殖方式

## 5. 与人类关系
- 驯化难度
- 用途
- 危险性
- 传说故事

## 6. 图像提示词
- 生成该生物外观的AI绘画提示词

## 7. 配文
- 仿博物学家笔记的描述（150字）
```

### 3. 随机创意生成器

**适用场景：** 激发创意灵感

**提示词：**
```
生成随机创意组合，激发灵感：

领域：[游戏/故事/产品/艺术]

请提供：

## 随机元素组合（10组）
每组包含：
1. **主题**：[随机主题]
2. **风格**：[随机艺术风格]
3. **情绪**：[随机情感]
4. **限制**：[一个创意约束]
5. **灵感**：基于这组元素的创意想法

示例：
1. 主题：时间旅行
   风格：赛博朋克
   情绪：怀旧
   限制：只能用三种颜色
   灵感：一个退休的时间警察在霓虹灯闪烁的老城区，用褪色的照片寻找失落的记忆...

## 创意练习
基于一个随机组合：
- 60秒速写主题
- 3分钟故事大纲
- 5个关键场景
```
